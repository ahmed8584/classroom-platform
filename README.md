# 🎓 منصة الحصة التفاعلية

منصة تعليمية عربية متكاملة تحوّل الحصة التقليدية إلى تجربة تفاعلية ممتعة.

## ✨ الميزات

- 👥 إدارة الصفوف والطلاب مع أفاتار ملوّن
- 🏆 نظام نقاط (فصلان دراسيان) وتقارير
- 🎮 18 لعبة تفاعلية جاهزة
- 📚 بنك أسئلة + استوديو دروس
- 📺 شاشة حصة مباشرة برمز انضمام
- 🤖 مساعد ذكاء اصطناعي (نص + PDF + صورة + OCR)
- 📊 تحليلات ورسوم بيانية

## 🚀 البدء

1. افتح المنصة
2. سجّل الدخول بكلمة المرور الافتراضية: `1234`
3. غيّر كلمة المرور من الإعدادات
4. أنشئ صفًا وابدأ

## 🔧 المتطلبات

- متصفح حديث (Chrome, Edge, Firefox)
- اتصال إنترنت
- حساب Google (لجدول البيانات)

## 📖 دليل الاستخدام

### للمعلم

1. **تسجيل الدخول**: كلمة المرور الافتراضية `1234`
2. **إدارة الصفوف**: من الشريط الجانبي → الطلاب
3. **إضافة طالب**: اكتب الاسم → إضافة
4. **بنك الأسئلة**: أضف أسئلة (mcq / tf / short)
5. **استوديو الدروس**: أنشئ درسًا بالوحدات
6. **تشغيل حصة**: بدء حصة من الدرس
7. **AI**: اكتب وصفًا أو ارفع PDF
8. **التقارير**: من التحليل → الرسم البياني

### للطالب

1. افتح رابط المنصة
2. اضغط "انضمام"
3. أدخل رمز الحصة + اسمك
4. ابدأ

## 🔒 الخصوصية

- البيانات في Google Sheets (خاص بحسابك)
- لا نستخدم بيانات الطلاب للتدريب
- كلمة المرور مشفّرة (SHA-256)

## 📞 الدعم

راجع صفحة "مركز المساعدة" داخل المنصة.
